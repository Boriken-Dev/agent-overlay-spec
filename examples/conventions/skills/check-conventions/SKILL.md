# Check conventions

List the overlay's root and say, for each conventional path (`bin/`, `lib/`, `rules/*.md`,
`CONTEXT.md`, `skills/*/SKILL.md`, `env`, `env.<ext>`, `setup.<ext>`), whether it is present and
what it does by default.
