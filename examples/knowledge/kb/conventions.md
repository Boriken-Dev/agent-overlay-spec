# Conventions

This file is markdown, the default: `${AOS_OVERLAY_NAME}` is replaced, and a line with only an `@path` takes
another file of the overlay in its place, as an import in a `CLAUDE.md` does.

@commit-format.md

Write `$${AOS_OVERLAY_NAME}` for the text `${AOS_OVERLAY_NAME}`. An `@` in a code block is never an include.
